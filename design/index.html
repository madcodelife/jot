两层结构

照 HIG 的 Liquid Glass 规则：材质只给浮在内容上方的控件层，正文不用。

功能层 · Liquid Glass（regular）浮窗外框、搜索框、提示胶囊。整个界面只有这一块玻璃，不叠玻璃。
内容层 · 纸面笔记正文、代码块。不透明，深浅色各一套；搜索命中用荧光笔黄。

在 NSH 里怎么做

大部分 NSH 现在就有；各平台的呼出键和刘海位置先在 Jot 自己的 Rust crate 里做。

要做的NSH 的做法状态
无边框、透明的浮窗窗口 frame: "none"、透明窗口、level: "floating"已有
macOS 的 Liquid GlassglassEffect: "regular"（macOS 26），更早的系统退回 backdropFilter 模糊已有
Windows 的 Acrylic窗口 backdrop: "popover"，在 Windows 11 上就是 Acrylic已有
Linux 的浮窗表面不透明的 popover 颜色，描边和阴影自己画；透明窗口上的阴影在 GNOME / KDE 上的表现要实测实现时确认
弹簧形变原生动画图的 spring driver，跑在主线程，不经过 JS；各平台只换 damping已有
托盘、备用快捷键nsh/desktop 的 Tray、GlobalShortcut；Linux 的托盘是 StatusNotifierItem，GNOME 要 AppIndicator 扩展已有
双击 ⌥ 呼出（macOS）Jot 的 Rust crate 监听修饰键（需要辅助功能权限）；没授权时退回备用快捷键Jot 里做
双击 Ctrl 呼出（Windows）Jot 的 Rust crate 用低级键盘钩子判断 Ctrl 连按两下，不需要权限Jot 里做
Super+J 呼出（Linux）GlobalShortcut 走 GlobalShortcuts portal（GNOME 48+、KDE）；没有 portal 时注册失败，提示去系统设置绑定已有
开机启动Application.loginItem()已有
正文编辑、Markdown 高亮nsh/base 的 Editor已有
灵动岛窗口level: "aboveDock"（在菜单栏、任务栏之上）、所有桌面空间都显示、点击穿透、无阴影已有
刘海的位置和大小先在 Jot 的 Rust crate 里读 NSScreen；之后可以提给 NSH，作为 displays() 的一个字段Jot 先做，再提 NSH
iPhone 版NSH 的 iOS 后端；底部搜索框、列表、全屏编辑器都是现有元素已有
小组件、分享扩展都是 App 扩展，NSH 目前不支持以后
主屏快捷操作（长按图标）Info.plist 的快捷操作加启动时的回调，NSH 是否支持要查待确认
减弱透明度 / 动态效果读系统设置，退回不透明底和淡入淡出实现时确认
桌面通知nsh 的 Notifications：标题、正文，点通知回到 App（按 id 认出是哪一条）；macOS、Windows、Linux 都有已有
通知上的按钮「完成」「10 分钟后」「打开」：NSH 的通知现在只有标题和正文，按下只报是哪一条。要提给 NSH：通知带几个按钮，按下时报按钮的 id。没有之前，点通知打开待办视图要提 NSH

需要你定的

  • 名字：Jot 只是代号。
  • Windows 呼出键：建议连按两下 Ctrl。单按 Alt 会激活当前窗口的菜单栏，连按 Alt 容易误触；备用快捷键先定 Ctrl+Alt+J。
  • Linux 快捷键：建议 Super+J。Wayland 下应用拿不到连按修饰键，只能注册普通组合键；要在 GNOME 和 KDE 上核对没被占用。
  • Windows 灵动岛位置：推荐屏幕上沿正中垂下的胶囊，和 macOS 在同一个位置，视线不用找。备选是右下角托盘上方弹出，贴近 Windows 通知的位置，但离视线远、和系统通知抢地方。
  • 灵动岛要不要给自己用：比如把文字拖到灵动岛上直接记一条。
  • 提醒的默认时间：只写日期不写时间时，默认 9:00。建议就用 9:00：早上开工前提醒，一天里还来得及做；如果你习惯晚上处理杂事，可以在设置里放一个「默认提醒时间」。另外「下午」「晚上」这种没有钟点的说法，建议 Claude 按 15:00 / 20:00 记，并在回复里说出来。
  • 通知上的「打开」按钮：HIG 不建议放只是打开 App 的按钮，点通知本身就会打开。建议 macOS 和 iPhone 只留「完成」「10 分钟后」，Windows 和 GNOME 照常放三个。
