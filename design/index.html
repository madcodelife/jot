Two layers

Following the HIG’s Liquid Glass rules: the material is only for the control layer floating above the content, never for the text.

Control layer · Liquid Glass (regular)The panel’s frame, the search field and hint capsules. This is the only glass in the interface; glass is never stacked.
Content layer · paperNote text and code blocks. Opaque, one set for light and one for dark; search hits in highlighter yellow.

Open decisions

  • Name: Jot is only a code name.
  • Windows summon key: double-press Ctrl, suggested. A single Alt press activates the current window’s menu bar, so a double Alt is easy to trigger by accident; the fallback shortcut is Ctrl+Alt+J for now.
  • Linux shortcut: Super+J, suggested. Under Wayland an app can’t see double-pressed modifiers and can only register ordinary key combinations; check that it’s free on GNOME and KDE.
  • Island position on Windows: recommended: a capsule hanging from the middle of the top edge, where it is on macOS, so the eye doesn’t have to look for it. The alternative pops up above the tray at the bottom right, near where Windows shows notifications, but far from where you’re looking and competing with system notifications.
  • Should the island be yours to use too: for example, drag text onto it to jot a note.
  • Default reminder time: a date without a time means 9:00. Suggested: keep 9:00, a reminder before the workday starts, with the day still ahead to get it done; if you deal with errands in the evening, a “Default reminder time” setting can change it. And for phrases without an hour, such as “afternoon” or “evening”, Claude should use 15:00 / 20:00 and say so in its reply.
  • The “Open” button on notifications: the HIG advises against a button that only opens the app, since clicking the notification already does. Suggested: only “Done” and “In 10 Minutes” on macOS and iPhone; Windows and GNOME keep all three.
